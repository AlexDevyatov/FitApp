# FitApp — варианты иконки

## v6 (по сплэшу SnapMeal, актуальная)

Знак — не «похожая» диафрагма, а тот же контур, что на сплэше: `build_icons_v6.py` читает path
из `res/drawable/ic_splash_logo.xml` и рисует его на новых фонах. Цвета сняты пипеткой с
[github-release-splash.png](../artifacts/release/github-release-splash.png): изумруд `#0F543B`/`#0D503A`,
мята `#98E2C3`, лаймовое и персиковое свечение `#BFE56F`/`#FFB77D`; крем `#F4F1E8` и ночь `#101613` — из `Theme.kt`.

Обзорный лист: [variants-sheet-v6.png](variants-sheet-v6.png). Каждый вариант — 1024×1024, круглая маска
и превью 48 dp; в папке лежит готовый `res/` для adaptive icon.

| № | Папка | Идея | Когда уместна |
|---|-------|------|---------------|
| 1 | `v6-01-splash-mint/` | Мята на изумруде ровно как на сплэше | Прямое продолжение сплэша, иконка и заставка читаются как одна вещь |
| 2 | `v6-02-splash-glow/` | Плюс градиент и лаймово-персиковые пятна | Самая «живая», но в 48 px пятна уже не видны |
| 3 | `v6-03-cream-emerald/` | Инверсия: изумрудный знак на кремовом | Светлые обои и белые подложки, где тёмная иконка теряется |
| 4 | `v6-04-lime-emerald/` | Акцентный лайм темы на изумруде | Самая заметная в списке приложений, но громче бренда |
| 5 | `v6-05-ink-mint/` | Мята на фоне тёмной темы | Ночной режим, минимализм |
| 6 | `v6-06-ring-mint/` | Диафрагма в кольце объектива | Читается как «камера + тарелка», но линия тоньше 2 dp на 48 px |

**Мой выбор:** №1 (`v6-01-splash-mint`) — совпадает со сплэшем пиксель в пиксель, один знак, два цвета,
ничего не теряется при уменьшении. №3 — запасной вариант, если иконка нужна светлой.

Монохромный слой (Android 13+ Themed icons) отдельно рисовать не нужно: знак — сплошной силуэт,
система сама перекрасит его, если в `mipmap-anydpi-v26/ic_launcher.xml` подставить тот же foreground
в `<monochrome>`.

### Все шесть уже в приложении

`build_icons_v6.py` раскладывает варианты по `app/src/main/res` (см. `write_app_icons()`):

| Ресурс | Что это |
|---|---|
| `drawable/ic_launcher_foreground{,_glow,_cream,_lime,_night,_ring}.xml` | знак в системе 108 dp, вписан в 72 dp |
| `drawable/ic_launcher_background_glow.xml` | градиент и два пятна для варианта «Свечение» |
| `values/ic_launcher_colors.xml` | фоны остальных пяти (`ic_launcher_background*`) |
| `mipmap-anydpi-v26/ic_launcher{,_glow,_cream,_lime,_night,_ring}.xml` | adaptive icon каждого варианта |

Дальше иконку выбирает пользователь: «Настройки → Оформление → Иконка приложения».
В Android нельзя поменять иконку запущенного компонента, поэтому каждая иконка — отдельный
`activity-alias` в манифесте (`.IconSplash`, `.IconGlow`, `.IconCream`, `.IconLime`, `.IconNight`,
`.IconRing`), включён всегда ровно один. Переключение — `ui/icon/AppIcons.kt` через
`PackageManager.setComponentEnabledSetting(DONT_KILL_APP)`: сначала включается новый алиас, потом
гасится старый, чтобы ярлык не исчезал между вызовами. Выбор лежит в DataStore (`app_icon`),
а при старте `FitAppApplication` сверяет его с включённым алиасом — после обновления приложения
манифест снова включает иконку по умолчанию, и без сверки выбор бы терялся.

Что меняется не везде: ярлык на главном экране — да; иконка приложения в «Настройках системы»
и в списке недавних задач остаётся `@mipmap/ic_launcher` (Изумруд), потому что она задаётся
у `<application>` и статична.

### Как посмотреть варианты без сборки

`python icons/build_icons_v6.py` — перерисовывает превью, лист и (заодно) ресурсы приложения
из `ic_splash_logo.xml`. Руками пути и цвета не правятся: следующий запуск их перезапишет.

Текущая иконка по умолчанию — «Изумруд» (мята на изумруде, как на сплэше).

## Как поставить выбранный вариант в приложение

Сейчас лончер — векторный adaptive icon:
`res/mipmap-anydpi-v26/ic_launcher.xml` → `res/drawable/ic_launcher_foreground.xml` + `@color/ic_launcher_background`.

Растровую картинку из этого набора нельзя просто положить в `ic_launcher_foreground`: система обрежет её по маске
(круг/сквиркл/квадрат) и сдвинет. Правильный путь:

1. Выбрать вариант, обрезать картинку до «безопасной зоны» — 66 из 108 dp по центру (≈61 % стороны),
   то есть содержимое должно занимать центральные ~61 % кадра, а не весь кадр.
2. Экспортировать foreground в 432×432 px (108 dp @ xxxhdpi) с прозрачным фоном; фон — либо
   `ic_launcher_background` из colors.xml, либо вторая картинка `background`-слоя.
3. Положить как `res/drawable-nodpi/ic_launcher_foreground.png` (или разложить по `mipmap-*dpi`) и оставить
   `mipmap-anydpi-v26/ic_launcher.xml` без изменений.
4. Проверить маску: круг, сквиркл, «squircle» Samsung и монохромный слой (Android 13+ Themed icons) —
   для монохрома нужна одноцветная версия того же силуэта.

Варианты v4 №1, №2, №3, №4 (плоские силуэты) переносятся в вектор руками почти без потерь; №5 тоже
(геометрия простая); №6 — текстовый badge, не подходит как основная иконка.
