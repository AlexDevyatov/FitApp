Арт для полноэкранного splash screen Android-приложения FitApp, стиль Material 3 Expressive.
Вертикальный кадр 9:16, изображение заполняет кадр целиком. Без рамки телефона, без макета
экрана, без статус-бара и любых элементов интерфейса, без водяных знаков и подписей по краям.
Плоская векторная графика, чистое поле, много воздуха, композиция строго по центру.
На экране только элементы, перечисленные ниже: никаких лишних фигур, точек, полос, рамок
и декора. Весь текст только на русском языке, ровные буквы без искажений.
Спокойный, тёплый, дорогой вид, точные ровные края фигур.
